AlexBooks for Windows 0.2.0 — the first run asks how this PC will use AlexBooks.

- **Just this PC**: looks for AlexBooks running on this computer and opens it; if it is not installed here yet, says so.
- **Network**: finds the office server by itself — servers on AlexBooks 1.25.3+ answer with their office name; older ones are found by their open port — or the address can be typed. No address is ever pre-filled.
- Same shell underneath: own window, own icon, remembers the window size.

Needs AlexBooks 1.25.3 on the server for the by-name search (older servers are still found by port).
