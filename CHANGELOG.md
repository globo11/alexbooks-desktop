# What's new — AlexBooks for Windows

## 1.4.1 — one uninstall, and a steady hello

- **Uninstalling AlexBooks** from Windows → Installed apps on the server PC also stops and removes the office server — one Yes to Windows, nothing to type. The office's data folder is kept.
- Each PC lets the office server know it is still open, so the office's records show when a workstation was last active, not only when it was opened.
- A PC whose office was set up again, and that has a just-downloaded package, goes straight to *Set up a new office* with it.

## 1.3 — double-click the package

- An emailed package opens in AlexBooks for Windows by itself: double-click the attachment, type the passphrase, done. The newest package on the PC is the one picked; a package older than a week says so.
- On the server PC, AlexBooks for Windows installs the office server and opens the office in the same window.

## 1.2 — updates that install themselves

- A newer AlexBooks for Windows installs by itself when AlexBooks starts on a PC — a short "Updating…" screen, then the office opens. The new icon.

## 1.1 — set up a new office from an emailed package

- *Set up a new office*: pick the package file, type its passphrase, and the office server installs on this PC.

## 1.0 — AlexBooks for Windows

- One window per PC that finds the office server on the local network, trusts it, and keeps itself up to date from it.
